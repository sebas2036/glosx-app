# Backlink Outreach & Distribution Pack — glosx.app

## 1. Auditoría de Widgets Embebibles ("Route cards" y "Guide cards")

Los widgets embebibles de `glosx.app` (Route cards y Guide cards) generan un fragmento HTML seguro tipo `<iframe>` o un tag script ligero para que los creadores de contenido y blogueros de viajes puedan incrustar itinerarios de tren en directo o guías multilingües en sus propias páginas web.

### Código HTML generado para inserción (`embed`):
Cuando un usuario copia el código de inserción de una *Route card* o *Guide card*, el snippet incluye un enlace directo, optimizado para SEO, con los atributos recomendados:

```html
<div class="glosx-widget-embed" data-route-id="zermatt-glacier-express">
  <iframe src="https://glosx.app/embed/route/zermatt-glacier-express" width="100%" height="380" style="border:none;border-radius:12px;" title="Live Train Route: Zermatt to St. Moritz via GlosX"></iframe>
  <p style="font-size:12px;color:#666;text-align:center;margin-top:4px;">Powered by <a href="https://glosx.app/?ref=embed_widget" target="_blank" rel="noopener">GlosX Train Planner</a></p>
</div>
```

**Análisis del enlace exacto:**
- **URL de destino:** `https://glosx.app/?ref=embed_widget` (o la ruta específica de la guía/ruta).
- **Atributos:** `target="_blank"` y `rel="noopener"` para proteger la navegación y transmitir autoridad de página (Link Juice) de forma limpia.
- **Valor SEO:** Cada sitio web de terceros que incrusta una tarjeta genera un backlink dofollow contextual hacia el dominio principal de `glosx.app`, acompañado de una mención de marca en texto ancla natural ("GlosX Train Planner").
